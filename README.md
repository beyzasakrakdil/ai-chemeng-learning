# AI in Chemical Engineering - Learning Notes

Personal implementations of concepts from  
*AI in Chemical Engineering: Unlocking the Power Within Data* (Romagnoli et al.)

Focus areas:
- Synthetic process data generation and cleaning
- Scaling and preprocessing
- Dimensionality reduction (PCA, t-SNE, UMAP)
- Clustering (KMeans, DBSCAN, HDBSCAN)

All code written from scratch.
